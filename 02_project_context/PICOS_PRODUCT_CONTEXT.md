# PICOS Product Context

PICOS means Political Intelligence and Campaign Operating System.

## Product Purpose

PICOS is intended to centralize campaign intelligence and operations for a political leader, campaign team, volunteers, booth coordinators, content teams, and war-room users.

Primary pilot context:

- Candidate: Uday Sangle.
- Constituency: Sinnar, Nashik, Maharashtra.
- Builder/project owner: Avhad Enterprises / Anuj Avhad.

## Core Outcomes

- Increase campaign efficiency.
- Centralize campaign data.
- Improve decision-making.
- Track voter sentiment.
- Manage volunteers.
- Monitor opponents.
- Run digital campaigns.
- Provide real-time intelligence.
- Improve election readiness.

## User Types

| User type | Expected access |
|---|---|
| Super Admin | Full system access for Avhad Enterprises |
| Candidate | View intelligence, approve campaigns, approve communication, view analytics |
| Campaign Manager | Manage operations, assign tasks, manage volunteers, track performance |
| Intelligence Team | Research, competitor tracking, issue tracking, sentiment and media analysis |
| Content Team | Social media, design, video, website, speech and press content |
| Volunteer | Limited task access, booth/village reporting |
| Booth Coordinator | Booth-level operations, worker tracking, local intelligence |
| Constituency Coordinator | Multiple booths, local issues, events, coordinator reporting |

## Module Map

| Module | Purpose | Key records |
|---|---|---|
| Political Intelligence | Track political environment | candidate, opponent, party, timeline, events, relationships |
| Constituency Intelligence | Understand Sinnar | villages, wards, zones, demographics, economy, voting trends |
| Booth Intelligence | Track booth strength | booth, voters, community mix, volunteers, strength rating |
| Voter Intelligence | Understand segments | voter segment, influencer segment, support level, priority |
| Issue Mapping | Track local problems | issue, severity, affected population, owner, political impact |
| Volunteer Management | Manage ground team | volunteer, location, booth, tasks, attendance, reports |
| WhatsApp Operations | Manage digital distribution | groups, broadcast lists, reach, engagement |
| Media Monitoring | Track media environment | articles, TV, YouTube, pages, journalists, sentiment |
| Social Media Management | Manage content and performance | posts, content calendar, platform metrics, sentiment |
| Event Management | Track meetings and rallies | events, attendance, follow-ups |
| War Room Dashboard | Single command view | alerts, performance, opponent moves, upcoming events |
| AI Assistant | Generate and retrieve campaign knowledge | speeches, releases, FAQs, issue analysis, recommendations |
| Election Analytics | Track win readiness | vote share, booth trends, community trends, predicted support |
| Grievance Management | Track citizen problems | complaint, status, priority, assigned person, resolution |
| Knowledge Base | Store reusable assets | speeches, photos, videos, articles, achievements, manifestos |

## MVP Recommendation

The first usable version should not start with prediction. It should start with reliable data capture:

1. Source and knowledge base.
2. Candidate, opponent, village, booth, volunteer, issue, media, and research-task databases.
3. Daily political intelligence brief.
4. Volunteer task tracking.
5. Issue/grievance intake and resolution status.
6. WhatsApp/social content calendar.
7. War-room summary dashboard.

Predictive scores should come later, after enough booth, volunteer, issue, and sentiment data exists.

## Success Metrics

- Volunteer growth.
- Booth coverage.
- Village coverage.
- Issue resolution rate.
- Media reach.
- Social engagement.
- Sentiment score.
- Community coverage.
- Campaign efficiency.
- Election readiness score.
- Winning probability score, only after data quality is sufficient.
