# Agent Instructions

Read `PROJECT_CONTEXT.md` before doing any substantive work in this repository.

## Project Lens

This is not a generic political campaign project. It is centered on Uday Sangle and the Sinnar constituency. Every recommendation, feature, analysis, dashboard, research task, or content idea should answer:

> How does this help Uday Sangle gain votes, influence, trust, organizational strength, public support, or election-winning capability in Sinnar?

If the answer is unclear, label the work as low priority or ask for the missing context.

## Source Discipline

- Use `02_project_context/SOURCE_MAP.md` to understand which PDFs are canonical.
- The two Campaign Strategy PDFs have identical extracted text. Treat `Uday Sangle Campaign Strategy.pdf` as the canonical text source and keep `(1)` as a preserved duplicate.
- Do not present claims from PDFs as externally verified unless a separate source is recorded.
- Current political/legal facts are unstable. Verify them before public-facing use.
- Keep facts, assumptions, and hypotheses separate.
- When adding new intelligence, record the source, date checked, confidence, and next verification step.
