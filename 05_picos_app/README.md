# PICOS Political Intelligence Module

This is the Next.js first screen for the PICOS Political Intelligence Command Center.

## Run

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Source Discipline

The current screen uses a dummy intelligence dataset shaped around Uday Sangle and Sinnar. Items touching vote totals, party status, or opponent legal status are marked as verification-gated and should not be used as public campaign claims without fresh source confirmation.
