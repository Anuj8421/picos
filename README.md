# Uday Sangle Political Intelligence Project

This workspace is organized as the reusable context base for the Uday Sangle political intelligence and campaign operating system project.

Start here:

- `PROJECT_CONTEXT.md` - single source of truth for the project.
- `AGENTS.md` - instructions for future Codex/AI work in this repo.
- `02_project_context/` - curated briefs, source map, PICOS product context, research backlog, and data dictionary.
- `01_sources/original_pdfs/` - preserved source PDFs copied from Downloads.
- `01_sources/extracted_text/` - extracted text and JSON page data from each PDF.
- `04_data_templates/` - CSV schemas for future research and campaign databases.

The project is centered on Uday Sangle in Sinnar, Nashik district, Maharashtra. All research, analysis, product design, and campaign planning should be judged by the master question:

> Does this increase Uday Sangle's political strength, voter trust, organizational influence, public support, or election-winning capability in Sinnar?

Facts in this project must remain source-tracked. Where documents conflict or current political/legal status may have changed, treat the item as a research task until verified from an official or primary source.
